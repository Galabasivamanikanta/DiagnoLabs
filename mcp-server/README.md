# DiagnoLabs Model Context Protocol (MCP) Server

Official Model Context Protocol (MCP) server for **DiagnoLabs** healthcare diagnostics platform. Connects Claude, ChatGPT, and AI agents directly to diagnostic laboratory discovery, test catalog pricing, and clinical lab report insight tools.

## Tools Provided

1. `search_diagnostic_labs` - Filter accredited diagnostic labs by city, area, or specialization.
2. `get_lab_tests_and_pricing` - Fetch test menu, turnaround times, and prices in INR.
3. `analyze_medical_report_insights` - Transform numeric lab results into patient-friendly insights.

## Quickstart

```bash
npm install
npm start
```
